# Known limitations

- The public skills are independently authored workflow guidance, not 80 bespoke editing engines. They need a capable agent, local media tools, and (for advanced animation or alignment) extra dependencies.
- Source prompt text was accessible and archived locally for comparison, but the source site's redistribution license was not established. The raw prompt archive is ignored by Git and must not be published without permission.
- Inventory metadata captures explicit source cues. A missing resolution, frame rate, aspect ratio, dependency, or approval requirement means the source prompt did not explicitly yield that field to the extractor; it is not evidence that the source's original workflow lacked it.
- Audio beat estimates and transcription/word timing depend on installed analysis tools. The skills prohibit presenting estimated timings as exact forced alignment.
- Preview-first review is an instruction-level experience; whether the host can display contact sheets depends on its tools.
- Only generated fixture media was used for helper smoke tests. The library has not been validated across real cameras, codecs, long-form footage, or all creative outcomes.
- No website was built or deployed, no domain is configured, and no search ranking is claimed.
